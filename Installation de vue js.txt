Éléments mémorisés mis à jour
Parfait ! On va donc reprendre l’intégration de Vue.js dans Laravel pas à pas, en expliquant chaque ligne, comme si tu décortiquais une recette de cuisine. Tu comprendras ce que chaque outil fait, pourquoi on l’utilise, et comment Laravel et Vue "discutent" entre eux.

🔧 1. Installation du projet
bash
Copier
Modifier
laravel new mon-projet
cd mon-projet
👉 Explication :

laravel new mon-projet : crée un projet Laravel tout neuf dans un dossier appelé mon-projet.

cd mon-projet : entre dans le dossier pour travailler dedans.

📦 2. Installer les dépendances frontend
bash
Copier
Modifier
npm install vue@3
npm install
👉 Explication :

npm install vue@3 : installe Vue version 3 (la version actuelle de Vue, utilisée avec Vite et plus performante).

npm install : installe les autres dépendances listées dans package.json, notamment Laravel Vite, Tailwind (si tu l’utilises), etc.

⚙️ 3. Configuration de Vite
Fichier : vite.config.js
js
Copier
Modifier
import { defineConfig } from 'vite'
import laravel from 'laravel-vite-plugin'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
        vue(),
    ],
})
👉 Explication ligne par ligne :

js
Copier
Modifier
import { defineConfig } from 'vite'
➡️ On importe la fonction defineConfig de Vite, qui permet d’écrire une configuration proprement typée.

js
Copier
Modifier
import laravel from 'laravel-vite-plugin'
➡️ On importe le plugin Laravel qui permet à Vite de bien intégrer les fichiers Laravel (Blade, assets, etc.).

js
Copier
Modifier
import vue from '@vitejs/plugin-vue'
➡️ Ce plugin permet à Vite de comprendre les fichiers .vue (sinon il ne saurait pas les interpréter).

js
Copier
Modifier
export default defineConfig({
➡️ On exporte la configuration Vite avec la fonction defineConfig.

js
Copier
Modifier
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
➡️ Le plugin Laravel prend deux fichiers d’entrée :

app.css : ton fichier de styles

app.js : ton point d’entrée JavaScript (où Vue est initialisé)
Et refresh: true permet à Laravel de recharger les fichiers automatiquement dans le navigateur pendant le développement.

js
Copier
Modifier
        vue(),
➡️ On ajoute le plugin Vue à la configuration.

📁 4. Initialisation de Vue
Fichier : resources/js/app.js
js
Copier
Modifier
import { createApp } from 'vue'
import App from './components/App.vue'

const app = createApp(App)
app.mount('#app')
👉 Explication ligne par ligne :

js
Copier
Modifier
import { createApp } from 'vue'
➡️ On importe la fonction createApp de Vue 3. C’est le point de départ pour initialiser une application Vue.

js
Copier
Modifier
import App from './components/App.vue'
➡️ On importe un composant Vue (qui s’appelle App.vue). C’est notre composant principal.

js
Copier
Modifier
const app = createApp(App)
➡️ On crée une instance de l’application Vue avec le composant App comme racine.

js
Copier
Modifier
app.mount('#app')
➡️ On "monte" l’application dans la page HTML, sur l’élément qui a l’ID app.

🧩 5. Créer un composant Vue
Fichier : resources/js/components/App.vue
vue
Copier
Modifier
<template>
  <div>
    <h1>Hello depuis Vue 👋</h1>
    <p>{{ message }}</p>
  </div>
</template>
➡️ template : c’est la partie HTML du composant. On affiche un message dynamique avec {{ message }}.

vue
Copier
Modifier
<script setup>
import { ref } from 'vue'

const message = ref('Bienvenue dans ton premier composant Vue avec Laravel !')
</script>
👉 Explication :

<script setup> est une nouvelle façon plus simple d’écrire les scripts dans Vue 3.

import { ref } from 'vue' : on importe ref, une fonction de Vue qui permet de créer des données réactives.

const message = ref(...) : on crée une variable message qui sera mise à jour automatiquement dans l’interface si sa valeur change.

vue
Copier
Modifier
<style scoped>
h1 {
  color: #42b983;
}
</style>
➡️ Le scoped permet d’appliquer les styles seulement à ce composant (et pas globalement à toute l’app).

🖼 6. Affichage du composant dans Blade
Fichier : resources/views/welcome.blade.php
blade
Copier
Modifier
<!DOCTYPE html>
<html>
<head>
    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
<body>
    <div id="app"></div>
</body>
</html>
👉 Explication ligne par ligne :

@vite(...) : directive Blade qui inclut les fichiers générés par Vite (ton JS avec Vue et ton CSS).

<div id="app"></div> : c’est ici que Vue "monte" son application (grâce à app.mount('#app') vu plus haut).

🚀 7. Lancer le projet
bash
Copier
Modifier
npm run dev
php artisan serve
➡️ npm run dev : lance Vite en mode développement.
➡️ php artisan serve : démarre ton serveur Laravel à http://127.0.0.1:8000.

Quand tu ouvres cette URL, tu vois le composant Vue qui s'affiche.
